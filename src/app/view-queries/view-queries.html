Use viewChild() to access an element declared in this component's template when a small DOM action, such as moving focus, is needed.

How this query works

  1. The input is marked with the #searchInput template reference.
  2. viewChild.required() returns a signal for that input.
  3. The actions read the signal and focus the native input element.
