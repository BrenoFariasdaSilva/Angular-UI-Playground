Reactive forms

Angular Validators

Validators turn user input into reliable form data. This page combines Angular’s built-in validators with one small form-level rule you can test as you type.

Built-in validator catalog

required

Rejects an empty value.

requiredTrue

Requires a checkbox to be checked.

email

Checks the standard email shape.

minLength

Sets a minimum text length.

maxLength

Sets a maximum text length.

pattern

Matches a value against a regular expression.

min

Sets a minimum numeric value.

max

Sets a maximum numeric value.
