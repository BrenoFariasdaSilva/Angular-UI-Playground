Application theming

One theme, every page

The control in the top-right corner changes the complete application between light and dark themes. It stays available while you navigate, so the choice is never more than one click away.

How the theme works

  1. 1

    Toggle the preference

    The root application updates its theme state when you select Light or Dark.

  2. 2

    Apply one document class

    app-dark is applied to the document element, making the choice global.

  3. 3

    Update every surface

    PrimeNG tokens and page-specific dark styles update cards, inputs, dialogs, and backgrounds.

  4. 4

    Remember the choice

    The selected theme is saved in browser storage and restored on your next visit.

Designed to stay visible

The fixed control uses a dark appearance in light mode and white appearance in dark mode. Its accessible label also explains the next action: “Switch to dark theme” or “Switch to light theme.”
