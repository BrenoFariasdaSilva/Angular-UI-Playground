Angular performance

Deferrable Views

Use @defer to split a standalone component into its own chunk and load it only when the user needs it.

What happens here

  1. The page renders its essential content immediately.
  2. Angular prefetches the preview component while the browser is idle.
  3. Clicking the placeholder loads and displays the deferred component.

Try the deferred preview

@defer (on interaction(loadPreview); prefetch on idle) { } @placeholder { } @loading (after 100ms; minimum 500ms) {

Loading the preview…

} @error {

The preview could not be loaded.
