Model Inputs

A component can expose a writable model() input so a parent can use concise two-way binding without defining a separate output.

How the values stay in sync

  1. The parent owns a quantity signal.
  2. The child receives it with [(quantity)].
  3. Calling quantity.update() in the child updates the parent signal.
